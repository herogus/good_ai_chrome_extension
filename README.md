# 顾得助手 - 多平台智能对话、总结与翻译工具

一个轻量级智能浏览器插件，支持与多平台大语言模型对话，并提供网页总结、翻译、文章管理、接口调试和自动化部署等功能，助您高效阅读网页内容、处理开发任务和管理个人知识。

---

## 🔧 核心功能

- 💬 **多平台大模型对话**  
  支持配置多种主流 AI 模型服务，也支持自定义接口（OPenAI兼容格式）；支持流式响应、会话历史、模型切换和思考模式。

- 🧠 **智能总结与网页问答**  
  自动提取网页主要信息，生成简洁摘要，支持图文理解、多页面问答和结合用户问题进行定向分析。

- 📝 **文章管理与 Markdown 编辑**  
  支持个人文章和目录管理、Markdown 编辑、即时预览、目录拖拽及文章导入导出，方便整理和分享内容。

- 🔌 **接口调试助手**  
  提供接口目录、请求管理和测试用例功能，支持常用请求格式、文件上传、身份认证、自定义环境和请求脚本，也支持从接口规范或文档导入接口。

- 🚀 **自动化部署**  
  提供部署商店，支持项目与服务管理，并通过配套的本地服务组件完成上传、远程部署和任务执行；支持部署流程控制、命令模板、参数配置、服务器管理及执行日志查看。

- 🌐 **网页翻译助手**  
  支持网页全文、选中文本和输入框文本翻译，可配置翻译范围和样式；针对 GitHub、技术文档、SVG 图表等复杂页面进行了适配。

- 🧰 **常用效率工具**  
  内置文本格式化与智能修复、编码转换、图片处理、网络模拟和页面自动化等工具。

- 📌 **智能悬浮窗与主题系统**  
  支持拖动、调整大小、全屏展开、智能贴边，以及亮色/暗色主题和多种主题配色，适配不同使用习惯。

## 🔐 插件权限说明

为保证功能正常运行，插件需申请以下权限：

| 权限名称 | 用途说明 |
|---------|----------|
| `activeTab`、`tabs` | 获取当前标签页信息，用于网页总结、翻译、问答和页面辅助功能。 |
| `storage`、`unlimitedStorage` | 保存模型配置、API Key、会话记录、文章、接口和部署数据。 |
| `scripting` | 在用户主动触发功能时执行网页内容读取、翻译和辅助操作。 |
| `sidePanel` | 提供浏览器侧边栏对话和工具入口。 |
| `nativeMessaging` | 与配套的本地服务组件通信，支持自动化部署的上传和任务执行。 |

> 📌 **隐私保护承诺**：插件不会在用户未触发功能时主动读取网页内容。API Key、模型配置、会话记录、文章和工具数据默认保存在本地浏览器中，不上传、不共享。
